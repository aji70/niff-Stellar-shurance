# Documentation

Welcome to the protocol documentation. These pages explain how the protocol
works end to end: how claims are created and settled, how voting and quorum
are enforced, how the treasury stays solvent, and where the contracts live on
each supported network.

## What you will find here

- **[Claims](/docs/claims)** — how claims are created, validated, and settled.
- **[Voting](/docs/voting)** — proposal lifecycle, voting power, and quorum rules.
- **[Treasury](/docs/treasury)** — funding, payouts, and solvency guarantees.
- **[Contracts](/docs/contracts)** — deployed contract addresses per network.

## How to read this documentation

Each page is authored in-repo as MDX and rendered statically. Use the sidebar
to move between sections, or the table of contents on the right to jump to a
specific heading within a page. Previous and next links at the bottom of every
page let you read the documentation in order.

<Callout type="info" title="Source of truth">
  This documentation is versioned alongside the code. If you spot something
  that is out of date, use the "Edit on GitHub" link on any page to propose a
  change.
</Callout>

## Getting started

If you are new to the protocol, start with [Claims](/docs/claims) to
understand the core primitive, then continue to [Voting](/docs/voting) and
[Treasury](/docs/treasury). When you are ready to integrate, the
[Contracts](/docs/contracts) page lists the addresses you need per network.
